# Gadget Panda · Maker Concept

**แหวนเป็นเซ็นเซอร์ — โค้ดเป็นของคุณ**

Gadget Panda ไม่ใช่แอปสุขภาพสำเร็จรูป  
เป็นชั้นโฮสต์ที่ Maker ใช้ดึง RING503PANDA ออกจากกล่องปิด แล้วต่อเป็นโปรเจกต์ของตัวเอง

```text
IDEA → CODE → PROTOTYPE → COMMUNITY
```

---

## สิ่งที่เป็น / สิ่งที่ไม่เป็น

| เป็น | ไม่เป็น |
|---|---|
| runtime สำหรับแหวนบน Mac / Linux / Windows / Pi | แอปนับก้าวแบบ Oura / Whoop |
| โปรโตคอลเปิด + API สั้น | แอปสุขภาพสำเร็จรูป |
| สตรีมดิบ: PPG, IMU, HR, อุณหภูมิ | คะแนน wellness ที่ล็อกในแอปมือถือ |
| จุดตั้งต้นให้ต่อ Unity, MQTT, แล็บ | สินค้าผู้บริโภคปิดระบบ |

Maker ซื้อแหวนเพื่อ **อ่านเซ็นเซอร์** ไม่ใช่เพื่อล็อกอินแอปยี่ห้ออื่น

---

## ชั้นของระบบ

```text
โปรเจกต์ของ Maker
  gesture / MQTT / Unity / แล็บ / แดชบอร์ด
        ▲
gadgetpanda  (MIT, Python)
  scan · connect · stream · set user · UI
        ▲
RING503PANDA
  BLE · PPG · IMU · HR · temp · sport
```

โฮสต์อยู่ที่คอมพิวเตอร์ แหวนเป็นอุปกรณ์ต่อพ่วง  
เส้นทางหลักของ Gadget Panda คือ **Python บนเครื่องที่เขียนโค้ดได้**

---

## Maker ที่หมายถึง

คนที่อยากได้ค่าจากนิ้วในไม่กี่นาที แล้วเอาไปทำอย่างอื่น

- สร้างท่าทางจากความเร่ง — tap, flick, หมุน
- ต่อบ้าน / เวที / งานศิลป์ ผ่าน MQTT หรือ WebSocket
- แล็บสรีรวิทยา: คลื่น PPG, ชีพจร, อุณหภูมิ
- ห้องเรียน: สแกน → สตรีม → plot โดยไม่ต้องเขียน GATT เอง

ไม่ได้ตั้งใจเป็นผู้ใช้ที่แค่ดูสรุปสุขภาพรายวัน

---

## สัญญาที่ใช้ทำงาน

1. **เปิดชั้นโฮสต์** — สแกน ต่อ สตรีม ตั้งโปรไฟล์ ได้จาก CLI และโค้ดสิบบรรทัด
2. **ค่าดิบมาก่อนสรุป** — PPG เป็นคลื่น IMU เป็นแกน HR แยกแหล่ง BLE กับประมาณจากแสง
3. **เลือกโหมดที่ดึง** — ไม่บังคับเปิดทุกเซ็นเซอร์พร้อมกัน
4. **โปรไฟล์อยู่ที่แหวน** — อายุ น้ำหนัก ส่วนสูง เขียนลงเครื่องได้
5. **เส้นปิดชัด** — ไม่เรียก restore / DFU จากเส้นทาง maker ปกติ

## สิบนาทีแรก

```bash
pip install -e ".[ui]"
gadgetpanda ring scan
gadgetpanda ring ui --mode ppg
```

จากนั้นแยกทางได้ทันที

| อยากได้ | ทำต่อ |
|---|---|
| ดูทุกค่า | `gadgetpanda ring ui` โหมดทั้งหมด |
| ชีพจรจากแหวน | โหมดชีพจร BLE |
| คลื่นแสง + BPM | โหมด PPG + ชีพจร |
| ต่อบ้านอัจฉริยะ | `examples/05_mqtt_bridge.py` |
| ท่าทาง | `gadgetpanda.gesture.MotionWatch` แล้วต่อโมเดลเอง |
| ตั้งตัวผู้ใช้ | `gadgetpanda ring user --age --weight --height` |

## สิ่งที่เปิดให้ชุมชนต่อ

- ตัวจำแนก gesture ที่ดีกว่า tap
- OSC / WebSocket สำหรับ Unity และ Processing
- บันทึก CSV สำหรับแล็บ
- เอกสารภาษาอังกฤษฉบับเต็ม
- โปรเจกต์ตัวอย่างที่ไม่ได้มีแค่ print

ชุมชนต่อที่ชั้นโฮสต์และโปรเจกต์ปลายทาง

---

## ประโยคจำ

Gadget Panda คือ **แพลตฟอร์ม maker สำหรับแหวน**  
ฮาร์ดแวร์เป็นเซ็นเซอร์ — เราทำชั้นที่เขียนต่อได้  
คุณทำสิ่งที่แหวนยังไม่รู้ว่าตัวเองทำได้
